# Лабораторна робота 5: Clean Architecture

## Опис проєкту
Це консольний застосунок чат-месенджера, розроблений на C# (.NET). 
Проєкт створено з метою демонстрації шаруватої архітектури (Clean Architecture), 
де кожен шар (Domain, Application, Infrastructure, Presentation) відокремлений 
і залежить лише від внутрішніх рівнів.

## Предметна область
Чат-месенджер. Застосунок дозволяє надсилати текстові повідомлення, 
зберігати історію та переглядати список повідомлень.

## Технології
- C# (.NET 9)
- Git та GitHub (для контролю версій)
