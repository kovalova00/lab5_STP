# Лабораторна робота 5: Clean Architecture

## Опис проєкту
Це консольний застосунок для обліку завдань (Task Tracker), розроблений на C# (.NET). 
Проєкт створено з метою демонстрації шаруватої архітектури (Clean Architecture), 
де кожен шар (Domain, Application, Infrastructure, Presentation) відокремлений 
і залежить лише від внутрішніх рівнів.

## Предметна область
Облік завдань. Застосунок дозволяє створювати нові завдання, переглядати їхній 
список та позначати їх як виконані.

## Технології
- C# (.NET 9)
- Git та GitHub (для контролю версій)

## Політика гілкування
- main: стабільний код
- develop: інтеграційна гілка
- feature/*: гілки під конкретні задачі
